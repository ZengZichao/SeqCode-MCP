SeqCode MCP

A Model Context Protocol server for the SeqCode Registry database

GitHub Repository · SeqCode Registry · MCP Protocol

SeqCode MCP is a Model Context Protocol (MCP) server that enables AI assistants such as Claude to directly query and retrieve microbial nomenclature information from the SeqCode Registry — the central repository for names of prokaryotes (Bacteria and Archaea) described from sequence data.

⚠️ Disclaimer: This is an unofficial, community-driven MCP server and is not affiliated with the SeqCode Registry organization. SeqCode and SeqCode Registry are trademarks/project names of their respective owners.

About the SeqCode Registry

The SeqCode Registry is part of the SeqCode initiative, which provides a path forward for naming the uncultivated — prokaryotes described from genome sequence data. It serves as the central repository for prokaryotic names proposed under the SeqCode nomenclature code.

Features

  • 18 MCP Tools covering all public SeqCode Registry REST API endpoints
  • Async HTTP Client built on httpx for high-performance requests
  • Full-Text Search across names, genomes, publications, authors, and subjects
  • Pagination Support on all list endpoints
  • Status Filtering by SeqCode, ICNP, valid, etc.
  • Error Handling with comprehensive, user-friendly messages
  • Zero Configuration — no authentication or API key required
  • Standard stdio Transport compatible with all MCP clients

Configuration & Usage

Configure in Claude Desktop

Add the following to your Claude Desktop configuration file:

Config file locations:
macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
Windows: %APPDATA%\Claude\claude_desktop_config.json 

{
  "mcpServers": {
    "seqcode": {
      "command": "python",
      "args": ["-m", "seqcode_mcp.server"],
      "cwd": "/path/to/seqcode-mcp"
    }
  }
}
If installed via pip install -e ., you can use the entry point directly: 
{
  "mcpServers": {
    "seqcode": {
      "command": "seqcode-mcp"
    }
  }
}

Run Directly

# Option 1: Command-line entry point
seqcode-mcp

# Option 2: Python module
python -m seqcode_mcp.server

Tool Highlights

get_name — Taxonomic Name Details

Retrieves comprehensive information about a prokaryotic name, including:

  • Rank — domain, phylum, class, order, family, genus, species, etc.
  • Status — e.g., Valid (SeqCode), Valid (ICNP)
  • Etymology & syllabification
  • Nomenclatural type — genome, name, or strain
  • Classification — full taxonomic hierarchy from domain to species
  • Quality check warnings for genomic data

get_genome — Genome Details

Retrieves detailed genome information including database accession, genome type (isolate/mag/sag/enrichment), and genomic features:

  • Completeness, contamination, GC content
  • 16S/23S rRNA gene counts and completeness
  • tRNA count, coding density, codon table
  • N50, contig count, assembly length

search_seqcode — Full-Text Search

Search the SeqCode Registry across multiple data types:

# Search for names containing "Spongiamicus"
search_seqcode(query="Spongiamicus", what="names")

# Search genomes
search_seqcode(query="GCA_988", what="genomes")

# Search publications
search_seqcode(query="cyanobacteria", what="publications")
